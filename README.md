# Sito Web

Questo repository contiene i file per un sito web.

## Struttura

- `css/` - File CSS
- `html/` - File HTML
- `js/` - File JavaScript
- `img/` - Immagini
- `php/` - File PHP
- `gioco/` - File del gioco
- `download/` - File per il download
- `secretcode/` - Codici segreti

## Utilizzo

Consulta i file nelle rispettive cartelle per i dettagli.
